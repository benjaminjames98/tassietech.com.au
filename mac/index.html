Questions

Useful answers before we talk.

Which Macs do you work on?

MacBook Air, MacBook Pro, iMac, and Mac mini.

My Mac says the startup disk is full. Can you help?

Yes. We work out what is taking up the space, safely clear what you do not need, and set up iCloud or external storage if it helps.

Can you help me move from a Windows PC to a Mac?

Yes. We transfer your files, photos, and email and help you get comfortable with your new Mac.

Can Macs get viruses?

It is less common than on Windows, but Macs can pick up adware, scam pop-ups, and malware. We can check and clean your Mac.

Can my Mac run the latest macOS?

We check your model and let you know which version it can safely run.

Can you set up Time Machine backups?

Yes. We set up automatic backups so your files are protected if anything goes wrong.
