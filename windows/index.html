Questions

Frequently Asked Questions

Common Windows questions, answered

Is Windows 10 still supported?

No. Microsoft ended support for Windows 10 in October 2025, so it no longer gets regular security updates. We recommend upgrading to Windows 11 or replacing the computer if it can’t run it.

Can my computer run Windows 11?

Check our minimum hardware requirements, or let us check it for you.

Will I lose my files if I upgrade to Windows 11?

No. We back up your files before upgrading and check everything is where it should be afterwards.

Why do my Windows updates keep failing?

Common causes are a full drive, corrupted update files or a driver conflict. We diagnose the cause and get updates installing again.

What does a blue screen error mean?

It means Windows hit a problem it couldn’t recover from, often a driver, update or hardware fault. If it keeps happening, get it checked.

Can you reinstall Windows for me?

Yes. We reinstall Windows cleanly, then restore your files, programs and settings.
